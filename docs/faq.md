# FAQ

## What is Avalanche Privacy Kit?

A toolkit for building privacy-first Avalanche apps on top of eERC without forcing every developer to learn the full protocol stack first.

## Who is this for?

Frontend or full-stack developers who want to ship confidential application flows on Avalanche.

## Is this a protocol replacement?

No. It is a developer-experience layer around official Avalanche privacy tooling.

## Does it hide all protocol details?

No. It hides the repetitive setup and common flow complexity, not the existence of the underlying system.

## Is this production-ready today?

Not yet. The project is still at the documentation and planning stage.

## Why not build the CLI first?

Because the toolkit itself needs to prove the right workflow before generator tooling hard-codes it.
